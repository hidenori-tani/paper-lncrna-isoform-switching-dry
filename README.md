# Silent isoform switching in lncRNAs

Analysis code for **"Silent isoform switching: pervasive tissue-specific lncRNA isoform regulation invisible to gene-level analysis"** (Hidenori Tani).

This repository quantifies *silent switching* — lncRNA genes whose isoform-usage composition changes significantly across tissues while their gene-level expression does not change (the differential-transcript-usage-positive, differential-gene-expression-negative, DTU+/DGE− case) — using GTEx long-read and short-read RNA-seq data. The central index is the **lncRNA Isoform Switching Index (lnc-ISI)**, the maximum pairwise Jensen–Shannon divergence of mean per-tissue isoform-usage vectors.

## Key results

- Of 463 switch-significant lncRNAs (GTEx v9 long-read, 9 tissues), **71 (15.3%)** are silent — invisible to gene-level differential-expression (DE) analysis.
- The silent fraction is **power- and DE-definition-dependent**: it falls to 4.6% in higher-powered GTEx v8 short-read data and to 2.2% when DE is tested across all nine tissues; a short-read subsampling power curve brackets the long-read estimate at matched sample sizes.
- 268/463 (57.9%) switch-significant genes change their dominant isoform across tissues (median differential exonic content 1,738 bp).
- RBP sequence-motif density does not systematically change during switching (rank-biserial |r| = 0.033; robust to length-matching) — a bounded negative result.

## Repository layout

```
code/                 analysis pipeline (pure-Python; no notebooks)
  isoform_metrics.py    lnc-ISI / JSD / visibility classification (unit-tested)
  run_landscape.py      Phase 2: lnc-ISI landscape + visibility (permutation test)
  run_functional.py     Phase 3.1: dominant-isoform switch + differential exons
  run_rbp.py            Phase 3.2: RBP sequence-motif change (negative result)
  run_replication.py    Phase 4: GTEx v8 short-read replication
  run_power_curve.py    short-read subsampling power calibration (Fig 7)
  make_figures.py       all figures (every displayed statistic computed, not hardcoded)
  sensitivity_de_all_tissues.py      DE-definition sensitivity (Supplementary Note S1)
  sensitivity_rbp_lengthmatched.py   length-matched RBP null (Supplementary Note S2)
  get_data.sh           downloads all public input data
tests/                pytest suite (109 tests)
conftest.py           makes code/ importable bare (no package; avoids stdlib `code` shadow)
```

## Reproducing the analysis

```bash
python -m venv .venv && source .venv/bin/activate
pip install numpy pandas scipy statsmodels matplotlib pytest

bash code/get_data.sh                 # download GTEx long/short-read TPM + GENCODE v26
python code/run_landscape.py          # B=10,000 permutations (seed 42)
python code/run_functional.py
python code/run_rbp.py
python code/run_replication.py
python code/run_power_curve.py
python code/make_figures.py           # figures + consolidated key_numbers.txt
python code/sensitivity_de_all_tissues.py
python code/sensitivity_rbp_lengthmatched.py
pytest -q                             # 109 tests
```

All randomness uses a fixed seed (42). Figure and reported statistics are recomputed from the processed data on every run.

## Data availability

All input data are publicly available from the **GTEx Portal** (project dbGaP accession phs000424; the transcript-level TPM matrices used here are open-access). GENCODE v26 lncRNA annotation/FASTA are from gencodegenes.org. Exact download commands are in [`code/get_data.sh`](code/get_data.sh). Raw matrices are large and are **not redistributed**; processed summary files are regenerated by the pipeline.
